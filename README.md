Extension qui va récupérer les titres et albums depuis les sons en lecture sur votre page pour les envoyer sur un websocket.

Site actuellements supportés :
 - soundcloud.com
 - music.youtube.com

Pour l'utiliser il vous suffit d'ajouter cette extension en mode non empaqueté.  
Pour cela consultez internet, le mode développeur devra être activé.
